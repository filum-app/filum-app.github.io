# Filum — site vitrine

Site statique de présentation de [Filum](https://kevdody971.github.io/filum-site/), logiciel de traçabilité et de conformité pour la R&D de dispositifs médicaux : un graphe de traçabilité unique (besoin → exigence → spécification → essai → preuve), les documents réglementaires générés depuis le graphe, et trois modules — risques ISO 14971, études CLSI, non-conformités & CAPA.
